# 客户交付 SOP

## 目标

把已签约客户从需求确认推进到正式上线，并保留可审计证据。

## 角色事实

- 交付经理：确认范围、维护计划、协调客户、整合最终结论。
- 方案架构师：完成技术方案、依赖清单和上线回滚设计。
- 验收工程师：执行验收用例、记录证据并给出通过或返工结论。

## 阶段

1. 交付经理确认合同范围和输入完整性。
2. 方案架构师在范围确认后编写方案。
3. 验收工程师在方案完成后设计并执行验收。
4. 交付经理检查证据；失败时把原任务退回对应角色，不新建丢失上下文的任务。

## 质量门

- 缺少合同范围时不得进入方案阶段。
- 没有回滚方案不得上线。
- 验收必须包含用例、实际结果、证据位置和状态。
